# stockAssetCalculator

日本株・米国株の銘柄コードと保有株数を入力すると、現在の株価と為替レートから総資産（円換算）を計算する静的Webアプリです。ビルド不要で `stockAssetCalculator.html` をブラウザで開くだけで使えます。

## 使い方

1. `stockAssetCalculator.html` をブラウザで開く
2. 市場（日本株／米国株）・銘柄コード・保有株数を入力して「追加」
   - 日本株はコード（例: `7203`）だけでOK。内部で `.T` を付与します
   - 米国株はティッカー（例: `AAPL`）をそのまま入力します
3. 自動で現在値・USD/JPYレートを取得し、円換算した評価額と総資産を表示します
4. 「現金・余力」欄に証券口座の円建て・ドル建ての現金残高（買付余力）を入力すると、円換算されて総資産に加算されます

## データ取得について

- 株価: Yahoo Finance の公開チャートAPI（`query1.finance.yahoo.com`）から取得します。ブラウザのCORS制限で直接取得できない場合は、複数の公開CORSプロキシ（`corsproxy.io` → `api.codetabs.com` → `api.allorigins.win`の順）を順番に試し、最初に有効な株価データが取れたものを使います。あるプロキシがHTTP的には応答してもレート制限メッセージなど有効な株価データでない場合は、その候補は失敗として扱い次の候補を試します（失敗の詳細はブラウザの開発者コンソールに出力されます）
- 米国株はドル建ての株価をそのまま取得し、別途取得したUSD/JPYレートを掛けて円換算します
- 取引所が休場中（時間外・休日など）の銘柄は、**直近セッションの終値**（その日の取引がすでに終わっていれば当日終値）を使用します。日足データ（`range=5d&interval=1d`）を取得して時系列の最新バーから終値を読むため、「その終値がどの営業日のものか」が必ず特定でき、テーブル上に「休場中・終値（8/17）」のように営業日付きで表示されます
  - `meta.regularMarketPrice`が前営業日のまま古くなっている場合でも、日足バー側に当日の終値があればそちらを採用します（両者のタイムスタンプを比較して新しい方を使います）
  - 寄付前（PRE）・時間外（POST）の場合はそれぞれの気配値（`preMarketPrice`/`postMarketPrice`）を優先します
  - 日足バーも`regularMarketPrice`も取得できない場合のみ、1つ前のセッション（前日）の終値にフォールバックします（「前日終値（推定）」と表示）
- 各銘柄・為替レートの「状態」欄にYahoo側の`marketState`（`REGULAR`/`CLOSED`/`PRE`/`POST`等）をそのまま表示するので、なぜその値が使われているかを確認できます

## 自動更新について

画面を開いたままにしておくと、株価・為替を自動で取り直します（右上の「自動更新」チェックボックスでオン／オフを切り替えられます）。

- **ザラ場中（取引時間中・気配値が動く時間帯）: 60秒ごと** — 保有銘柄または為替のいずれかの`marketState`が`REGULAR`/`PRE`/`POST`のとき、リアルタイムに近い値を反映します
- **全銘柄が休場中: 10分ごと** — 寄り付きを拾えれば十分なため間隔を空け、無料の公開プロキシへのリクエストを抑えます

現在の更新間隔と次回取得予定時刻はチェックボックスの隣に表示されます。ブラウザのタブが非表示の間は取得を止め、タブに戻った時点ですぐに取り直します。
- 為替レート（USD/JPY）: Yahoo Finance のライブ市場データ（`JPY=X`）から現時点のレートを取得します。為替市場が休止中（週末など）は前回終値にフォールバックします。Yahoo側の取得に失敗した場合のみ `exchangerate-api.com` の無料APIにフォールバックします
- どちらも取得に失敗した場合は、テーブル上の「現在値」欄やレート欄に手動で数値を入力すれば計算に反映されます
- 各リクエストにはキャッシュバスター（タイムスタンプ）を付与し、`cache: 'no-store'`も指定して、ブラウザやCORSプロキシに古いレスポンスをキャッシュされたまま使い続けないようにしています
- 取得経路（直接／各CORSプロキシ）は7候補を用意し、**起動時に全候補へ同時にリクエストして最初に有効な株価データを返した経路を採用**します。以降はその経路だけを使うため、1銘柄あたり1リクエストで済みます。使っている経路は画面右上に「経路 ○○」と表示されます
  - 候補を順番に試すと、死んでいる経路のタイムアウトが積み上がって1銘柄に数十秒かかってしまうため、経路の探索だけは並列で行います
  - タイムアウトは4秒。採用中の経路が失敗した場合は、その場で経路を破棄して探索し直します
  - 銘柄の取得自体は150ms間隔で順番に行い、レート制限を避けます
- 取得に失敗した銘柄は、前回取得できたときの値を表示したまま「表示中は前回値」と明示します（欄の数値が最新値だと誤解しないため）
- 銘柄ごと・為替レートに「最終取得」（または失敗時は「最終試行」）の時刻と、返ってきたデータ自体の時刻である「データ時刻」（Yahoo側の`regularMarketTime`）の両方を表示します
  - 「最終取得」だけが進み続け、「データ時刻」が特定の日時のまま変わらない場合は、取得リクエスト自体は成功しているものの、取得先（Yahoo、または経由しているCORSプロキシ）が古いデータ・古いキャッシュを返し続けていることを意味します。このアプリ側のキャッシュ制御ではどうにもできない、外部サービス側の問題です
  - 「最終取得」自体が更新されない場合は取得処理そのものが失敗しているので、エラー表示や手動入力を確認してください

保有銘柄・現金余力の入力値はブラウザの `localStorage` に保存され、再読み込みしても保持されます。

## 前日比について

総資産、および銘柄ごとの現在値の「前日比」は、いずれも日本時間 **6:00** と **15:30** の2つの基準時刻のうち、直近のものと比較して表示します。

- 例: 7:00にチェック → 同日6:00の値と比較
- 例: 23:00にチェック → 同日15:30の値と比較
- 例: 5:00にチェック → 前日15:30の値と比較

このアプリは常駐サーバーを持たない静的ページのため、6:00/15:30ちょうどの値を必ず記録できるわけではありません。各基準時刻を過ぎてから最初に画面を開いた／更新したタイミングの値を、その区間の基準値として `localStorage` に記録し、以後はその値と比較します（タブを開いたままにしていれば、境界時刻ちょうどに自動で再取得・記録します）。基準値の記録時刻が実際の基準時刻とずれている場合は、前日比にマウスを乗せると実際の記録時刻を確認できます。

銘柄ごとの前日比は、**円換算した評価額の増減**で表示します。米国株はUSD建ての株価をUSD/JPYレートで円に換算してから比較するため、総資産の前日比と単位が揃い、株価の動きと為替の動きの両方が反映されます。

基準値は「1株あたりの円価格」で記録し、表示額にはその時点の保有株数を掛けています。そのため後から保有株数を変更しても変化率（%）はずれません。前日比にマウスを乗せると1株あたりの変動額も確認できます。

手動入力した価格や取得エラー時は、値が最新でないため前日比を記録・表示しません（取得に失敗している銘柄の行に前日比が出ないのはこのためです）。

前日比の色は日本の株式表示の慣例に合わせ、上昇（プラス）を赤、下落（マイナス）を緑で表示します。

## 注意事項

- 利用している外部APIは無料の非公式・パブリックエンドポイントのため、レスポンス仕様の変更や利用制限により取得できないことがあります
- 表示される評価額・前日比は概算です。投資判断には利用しないでください
