# stockAssetCalculator

日本株・米国株の銘柄コードと保有株数を入力すると、現在の株価と為替レートから総資産（円換算）を計算する静的Webアプリです。ビルド不要で `stockAssetCalculator.html` をブラウザで開くだけで使えます。

## 使い方

1. `stockAssetCalculator.html` をブラウザで開く
2. 市場（日本株／米国株）・銘柄コード・保有株数を入力して「追加」
   - 日本株はコード（例: `7203`）だけでOK。内部で `.T` を付与します
   - 米国株はティッカー（例: `AAPL`）をそのまま入力します
3. 自動で現在値・USD/JPYレートを取得し、円換算した評価額と総資産を表示します

## データ取得について

- 株価: Yahoo Finance の公開チャートAPI（`query1.finance.yahoo.com`）から取得します。ブラウザのCORS制限で直接取得できない場合は、パブリックCORSプロキシ（`api.allorigins.win`）経由で再試行します
- 為替レート（USD/JPY）: `exchangerate-api.com` の無料APIを利用します
- どちらも取得に失敗した場合は、テーブル上の「現在値」欄やレート欄に手動で数値を入力すれば計算に反映されます

保有銘柄はブラウザの `localStorage` に保存され、再読み込みしても保持されます。

## 注意事項

- 利用している外部APIは無料の非公式・パブリックエンドポイントのため、レスポンス仕様の変更や利用制限により取得できないことがあります
- 表示される評価額は概算です。投資判断には利用しないでください
